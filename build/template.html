How it works

A five-step pipeline from raw text to ranked opportunities

1 · Collect117,037 public entries from 13 sources, merged into one master file with source, rating, date, country and app version.
2 · CleanKeep English text, parse dates, group source variants. Relative dates such as "2 weeks ago" are left out of trends.
3 · GateA review enters the retrieval set only if one sentence has a photo noun, a finding action and a friction cue. Forum posts must name Google Photos.
4 · CodeRules tag problem (17), item type (8), clues remembered (7), memory gaps (4), search style (6), workaround (7).
5 · CompareReach, pain, momentum and unmet need feed a re-weightable opportunity score with a stability test.
